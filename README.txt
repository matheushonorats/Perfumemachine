MEU PERFUME — MVP PWA

Arquivos prontos para hospedagem estática gratuita.

FORMA MAIS FÁCIL (Cloudflare Pages / GitHub Pages):
1. Crie uma conta gratuita no GitHub.
2. Crie um repositório e envie todos estes arquivos.
3. Ative GitHub Pages em Settings > Pages > Deploy from branch.
4. Abra o endereço publicado no Safari do iPhone/iPad.
5. Toque em Compartilhar > Adicionar à Tela de Início.

IMPORTANTE:
- Os dados ficam no armazenamento local de cada aparelho.
- Nesta primeira versão, iPhone e iPad não sincronizam entre si.
- Para sincronização, a próxima etapa é conectar Firebase ou Google Sheets.
- O clima automático exige permissão de localização e HTTPS, fornecido pela hospedagem.
